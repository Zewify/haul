- Pausing a stream download (HLS or DASH) pauses it. It used to carry on and save the pieces it had half fetched as if whole, which left a glitch in the video, or fail with "Not an HTTP response." Resuming now gives the exact file.
- A connection that drops before the server answers is retried instead of failing the download.
- Stream retries are written to Komizo's log, so a stalled download can be diagnosed.
