- Haul is now called Downhaul. Another free Mac download manager was already called Haul, so this one took a name of its own. Nothing else changes: same app, same features, same install command, now at `zewify.com/downhaul/`.
- Updating from Haul removes the old Haul.app. Downhaul starts with an empty download list and asks to connect your browser again, because a renamed Mac app gets a fresh place for its data.
- In `chrome://extensions`, remove the old Haul extension and load Downhaul's from `~/Library/Application Support/Downhaul/Extension` (Developer mode, then Load unpacked). Downhaul's Settings, under Browser, copies the path.
