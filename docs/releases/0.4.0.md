- Downhaul is now called Komizo, from the Greek for "I carry, I bring home". Same app and features, now at `zewify.com/komizo/`; the old install command still works.
- Updating removes the old Downhaul.app (or Haul.app). Komizo starts with an empty download list and asks to connect your browser again, because a renamed Mac app gets a fresh place for its data.
- In `chrome://extensions`, remove the old extension and load Komizo's from `~/Library/Application Support/Komizo/Extension` (Developer mode, then Load unpacked). Komizo's Settings, under Browser, copies the path.
